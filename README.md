# Ticket térmico

Efecto de checkout: al confirmar el pago, una terminal expulsa un recibo de papel por la ranura, con vibración mecánica, borde dentado y estados `Processing → Printing → Order complete`.

HTML + CSS + JS puro en un solo archivo (`index.html`). Sin librerías, sin imágenes, sin backend.

## Uso

Abre `index.html` en el navegador. Para adaptarlo, cambia producto, montos, moneda, orden, tarjeta y fecha en el markup, y pon el logo del cliente en `.mark` y `.p-mark`.

Respeta `prefers-reduced-motion`.
